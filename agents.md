# AI Development Agents & Tools

This project leverages modern Generative AI agents and tools to accelerate development, optimize architectural decisions, and maintain high code quality.

## Development Agents used in this project

- **Claude Code:** Used for complex codebase refactoring, feature implementation, and architectural analysis.
- **Gemini CLI:** Orchestrates the development lifecycle, manages documentation, and automates repetitive tasks.
- **Amazon Q Developer:** Assisted in cloud-native service design and AWS infrastructure optimization.
- **GitHub Copilot:** Integrated into the IDE for real-time code suggestions and boilerplate generation.

## Agent-Led Enhancements

1. **Architecture Externalization:** Transitioned from hardcoded data to a JSON-driven configuration using AI-assisted refactoring.
2. **UI Component Generation:** Developed high-end Tailwind CSS components (Timeline, Skills Grid, Certification Cards) with AI-guided design patterns.
3. **Automated Documentation:** Kept `README.md` and `GEMINI.md` synchronized with codebase changes through agentic workflows.
4. **Data Extraction:** Utilized AI to extract and structure data from legacy resume formats (DOCX/PDF) into the new system model.
